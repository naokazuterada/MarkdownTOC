# MarkdownTOC - 4.3.0

## New features

- Support multiple TOCs in a document. All of the TOCs are refreshed, and the new attributes `start="top"` (list the headings before the TOC too, e.g. an index at the end of the document) and `scope="section"` (list only the headings in the section which the TOC is in) control the range of each TOC Ref: [#51](https://github.com/naokazuterada/MarkdownTOC/issues/51), [#167](https://github.com/naokazuterada/MarkdownTOC/issues/167)
- Insert TOC inserts a new TOC even when the document already has one. The new TOC inherits the attributes of the first TOC except for `levels`, `start` and `scope`, and gets `scope="section"` when it is inserted in a section
- Auto-complete attribute names, their values and the close tag while typing in the `<!-- MarkdownTOC ... -->` tag Ref: [#148](https://github.com/naokazuterada/MarkdownTOC/issues/148)

## Changes

- Number duplicate heading ids over the whole document like GitHub does. Links in the TOC pointed to a wrong heading when a same-named heading was out of the TOC (other levels, excluded, or before the TOC) Ref: [#176](https://github.com/naokazuterada/MarkdownTOC/issues/176)
- Insert TOC in the middle of a line inserts the TOC below the line instead of splitting it
- Improve performance of generating TOCs in a large document

## Notes

- Insert TOC no longer only refreshes the existing TOC. Use Update TOC or save the document to refresh TOCs.
- The second and later TOCs in a document are now refreshed. If you maintain them by hand, their contents will be replaced.
- Ids in the TOC may change in the cases fixed by #176. They now match the actual heading ids on GitHub.
