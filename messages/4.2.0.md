# MarkdownTOC - 4.2.0

## New features

- Add `autorun_extensions` setting to customize the file extensions that refresh the TOC on save (e.g. add `.txt`) Ref: [#169](https://github.com/naokazuterada/MarkdownTOC/issues/169)

## Changes

- Fix crash when `levels` or `bullets` is written as a comma separated string in the user settings; both a string and an array are now accepted Ref: [#165](https://github.com/naokazuterada/MarkdownTOC/issues/165), [#166](https://github.com/naokazuterada/MarkdownTOC/issues/166)
- Skip an invalid regex in `id_replacements` instead of failing the whole TOC generation Ref: [#175](https://github.com/naokazuterada/MarkdownTOC/issues/175)
- Update README: fix the configuration example, and add `.mdx` to the supported file extensions
